# House Price Prediction Using Regression
## Objectives

- Understand supervised learning and regression.
- Inspect and prepare a real-estate dataset.
- Explore relationships between house features and house prices.
- Split the data into training and testing sets.
- Build and compare regression models.
- Evaluate predictions using MSE, MAE, RMSE, R², and adjusted R².
- Implement batch, stochastic, and mini-batch gradient descent.
- Use residual plots and training-versus-testing errors to discuss model fit.

## Dataset

**File:** `RealEstate_HousePrice_Dataset_4200.xlsx`

The supplied Excel dataset contains 4,200 records and 12 columns.

| Column | Description |
|---|---|
| `house_id` | Unique property identifier; excluded from model features |
| `area_sqft` | House area in square feet |
| `bedrooms` | Number of bedrooms |
| `bathrooms` | Number of bathrooms |
| `location_score` | Numeric score describing location |
| `age_years` | Property age in years |
| `distance_city_km` | Distance from the city in kilometres |
| `lot_size_sqft` | Lot size in square feet |
| `has_garage` | Indicates whether the property has a garage |
| `has_pool` | Indicates whether the property has a pool |
| `renovation_years_ago` | Years since the last renovation |
| `house_price_inr` | Target variable: house price in Indian rupees |

The notebook removes duplicate rows and records without a target value, then separates the target from the input features. Missing numeric feature values are filled using the feature median.

## Models and Analysis

### 1. Simple Linear Regression
Uses `area_sqft` as the only input feature. The notebook displays the fitted line, slope, intercept, and a residual plot.

### 2. Multiple Linear Regression
Uses the available property features to predict house prices. The notebook compares its test-set performance with simple linear regression and displays the fitted coefficients.

### 3. Polynomial Regression
Fits degree-2 and degree-3 polynomial models using house area. Their curves and test errors are compared with the simple linear model.

### 4. Gradient Descent
Implements the following update methods from scratch for a linear model:

Batch gradient descent:** updates parameters using all training records.
Stochastic gradient descent:** updates parameters using one record at a time.
Mini-batch gradient descent:** updates parameters using small groups of records.

The notebook plots the loss history and reports test RMSE for each method.

## Evaluation Metrics

- **MSE (Mean Squared Error):** average squared prediction error; large errors receive a larger penalty.
MAE (Mean Absolute Error):** average absolute prediction error, in rupees.
RMSE (Root Mean Squared Error):** square root of MSE, in rupees.
R² score:** compares model predictions with a baseline that predicts the mean target value.
Adjusted R² score:** adjusts R² based on the number of predictors and observations.

Lower MAE and RMSE generally indicate smaller prediction errors. A higher R² is generally preferable, but metrics should be considered together. The notebook calculates results from the supplied data; results can vary if the dataset or train/test split changes.
