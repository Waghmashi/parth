Supervised Learning: It is a type of machine learning where the model is trained on labeled data (input-output pairs). The goal is to learn a mapping function from input variables to the output variable so it can predict the output for new data.

Regression vs Classification: Regression predicts continuous numerical values (like price, temperature). Classification predicts discrete categorical labels (like Yes/No, Cat/Dog).

Simple Linear Regression: It models the relationship between one independent variable (X) and one dependent variable (Y) by fitting a straight line:

Assumptions of Linear Regression: 1. Linearity (relationship is linear), 2. Independence of errors, 3. Homoscedasticity (constant variance of errors), 4. Normality of errors.

Bias-Variance Trade-Off: Bias is error from erroneous assumptions (underfitting). Variance is error from sensitivity to small fluctuations in training set (overfitting). We need a balance to minimize total error.

Overfitting vs Underfitting: Overfitting is when the model learns noise in training data and performs poorly on test data. Underfitting is when the model is too simple to capture the underlying pattern.



Task 26: Analyze Bias and Variance

Simple Linear Regression: High Bias (underfitting). It assumes a straight line, which is too simple for complex real estate data.

Multiple Linear Regression: Balanced. It captures more features, reducing bias, but not so complex that it overfits heavily.

Polynomial Regression: Low Bias, High Variance. If the degree is too high, it fits the training data perfectly but fails on new data (overfitting).

Task 27: How complexity affects error
As model complexity increases (Simple -> Multiple -> Polynomial), Bias decreases (model fits training data better), but Variance increases (model becomes sensitive to noise). The total error follows a U-shape.

Task 28: Best Balance
The Multiple Linear Regression model often provides the best balance for this dataset. It captures the main drivers (Area, Location, Bedrooms) without the extreme variance of high-degree polynomial models.
